# 顺德周末 · 2026年11月6–8日

两人从深圳北周五晚出发、周日返深的静态旅行攻略。以大良钟楼／清晖园附近连住两晚为主线，参考厦门攻略的每日行程、路线地图、景点详情与美食卡片结构。

## 在线地址

- 网站：https://zhongzihang.github.io/2026_ShunDe_Travel/
- GitHub：https://github.com/zhongzihang/2026_ShunDe_Travel

## 使用

网页不依赖构建、不需要地图密钥，没有跟踪统计或服务器数据存储。直接打开 `index.html` 即可使用；也可以在目录启动静态 HTTP 服务。

- 三日切换，周日可替换顺峰山／博物馆／容桂；地图与文字导出同步。
- 点地图地标和景点卡看介绍、时间、来源与高德导航。
- 按类别筛选美食；酒店链接用于核对指定两晚价格。
- 两人两晚预算可调整；清单仅保存在当前设备的浏览器。
- 下载文字行程；浏览器打印功能可存为 PDF（这是浏览器打印入口，不是已生成的离线PDF文件）。

地图和美食图案是示意插画，不可用作真实导航或实拍证明。地图无需外部瓦片，导航按钮跳往高德网站。所有景点实拍都在 `assets/`，有作者和许可记录。

## 内容与查证

`data.js` 保存景点、食品、酒店、三日行程、铁路候选及来源；`research/transport-verification.json` 保存铁路／地铁公开数据核验记录。核对日期为2026年11月4日，铁路快照约为北京时间00:40。

候选去程 G6244 11/6 19:48–20:34；返程 G6033 11/8 18:01–18:31。本次二等座查询为74.5元/人每程，余票必须购票时重查。未购票或订房，酒店200–350元／晚是筛选目标，不是指定日期实时报价。

静态信息与实时数据分开记录：交通方向、票价和景点常规开放来源可查；打车、步行耗时和吃喝金额为规划估算。下雨时按博物馆官方公告核对开放。网站不展示虚构的平台评分或未核实天气预报。

## 检查与维护

```text
node --test tests/*.test.cjs
node --check app.js
node --check data.js
```

`core.js` 是预算、餐饮筛选、导航URL与文本导出的纯逻辑；`app.js` 处理界面交互；`styles.css` 包含手机、桌面及打印样式。GitHub Actions 在推送 `main` 后执行测试并部署 GitHub Pages。

发布到其他仓库时，更新HTML中的仓库链接与本说明中的访问地址。无需更改资源相对路径。保留摄影署名与CC BY-SA 4.0许可证链接。
